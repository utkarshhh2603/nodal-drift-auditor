How it works

Rules first. LLM only for the residual.

01

Replay

Recomputes the expected daily balance purely from the recorded books — naive on purpose, so it drifts exactly where the records do.

02

Decompose

Enumerates every candidate cause per day and subset-sums them against the total drift — multiple incidents on one day are each reported separately, not blurred together.

03

Classify

Duplicate settlement, stuck refund, duplicate chargeback, or fee-sweep timing (confirmed only once a matching reversal actually shows up later in the series).

04

LLM review

Only touches what the rules can't explain. It never re-derives arithmetic the rule engine already got right.
